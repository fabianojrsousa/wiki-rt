# Fórum Radar RT (Fase 1) — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fórum de perguntas e respostas dentro do radarrt.com, com login Google, leitura pública, SEO por tópico e moderação posterior.

**Architecture:** Astro passa a `output: 'hybrid'` com `@astrojs/cloudflare`. Só `/forum` e `/forum/t/:id` são renderizadas no servidor (leitura pública com a chave anon); todo o resto continua estático. Login e escrita acontecem no navegador com `@supabase/supabase-js`, e o RLS do Postgres (Supabase Cloud, São Paulo) garante as permissões.

**Tech Stack:** Astro 4.16, `@astrojs/cloudflare` 11.2.0, `@supabase/supabase-js` 2.x, Supabase Cloud (Postgres + Auth Google), Vitest 2.1.9, Cloudflare Pages (deploy via GitHub Actions + wrangler).

**Spec:** `docs/superpowers/specs/2026-09-30-forum-design.md`

## Global Constraints

- Nenhuma cor ou fonte nova: só tokens de `src/styles/global.css` (`--display`, `--corpo`, `--dado`, `--superficie*`, `--borda*`, `--tinta*`, `--link`, `--destaque*`, `--confirmado*`, `--critico*`, `--previsto*`, espaçamentos `--e-*`, raios `--r-*`).
- Textos de interface em português do Brasil.
- Limites (iguais no banco e no navegador, contados em caracteres Unicode após `trim`): título 10–150; pergunta 20–10.000; resposta 5–10.000; apelido 2–40.
- Anti-spam no banco: 5 tópicos e 20 respostas por usuário por hora.
- 20 tópicos por página na lista. Descrição de SEO: 155 caracteres.
- URL do tópico: `/forum/t/<id>-<slug>`; o servidor usa só o `id` e redireciona (301) para a URL canônica.
- Variáveis: `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_ANON_KEY`. A chave `service_role` nunca entra no site nem no repositório.
- Chave de sessão no `localStorage`: `radarrt-auth`.
- Páginas não-fórum não carregam `@supabase/supabase-js`.
- O repositório é público: nunca gravar e-mails, chaves secretas ou IDs de conta em arquivos versionados.
- O Fabiano edita `Base.astro` e `index.astro` em paralelo: rodar `git pull --rebase origin main` antes de cada commit que toque esses arquivos.
- `git push` é feito pelo Felipe (hook bloqueia push pelo Claude).

## Review Focus

1. **Título ou texto com emoji, acentos ou só espaços**: o contador do navegador deve concordar com o `char_length` do banco (emoji conta 1, espaços nas pontas não contam). Teste em `contarCaracteres` (Tarefa 2).
2. **Título sem letras ou números** (ex.: `???`): a URL não pode terminar em `-` vazio; slug cai para `topico`. Teste em `slugify` (Tarefa 2).
3. **Parâmetro `volta` malicioso** (`//site-externo.com`, `/\site`, `https://…`): o login deve voltar só para caminhos internos. Teste em `caminhoSeguro` (Tarefa 2).
4. **Query string inválida na lista** (`?pagina=abc`, `?pagina=-3`, `?categoria=inexistente`, `?aba=xyz`): a página abre na primeira página, sem filtro inválido. Teste em `lerFiltros` (Tarefa 2).
5. **Link colado com pontuação no fim** (`…ver https://www.gov.br/lei.`): o ponto final não entra no link. Teste em `formatarTexto` (Tarefa 2).

  it('ignora espaços e quebras nas pontas', () => {
    expect(contarCaracteres('  \n abc \n ')).toBe(3);
  });
  it('conta emoji como um caractere', () => {
    expect(contarCaracteres('CBS 👍')).toBe(5);
  });
  it('conta acentos como um caractere', () => {
    expect(contarCaracteres('ação')).toBe(4);
  });

describe('formatarTexto', () => {
  it('escapa HTML do usuário', () => {
    expect(formatarTexto('<script>alert(1)</script>')).toBe('<p>&lt;script&gt;alert(1)&lt;/script&gt;</p>');
  });
  it('separa parágrafos por linha em branco e quebra linhas simples', () => {
    expect(formatarTexto('a\nb\n\n  \nc')).toBe('<p>a<br>b</p><p>c</p>');
  });
  it('transforma URL em link com rel seguro', () => {
    expect(formatarTexto('veja https://www.gov.br/x')).toBe(

    );
  });
  it('não inclui pontuação final no link', () => {
    expect(formatarTexto('ver https://www.gov.br/lei.')).toBe(

    );
  });
  it('não linka javascript:', () => {
    expect(formatarTexto('javascript:alert(1)')).toBe('<p>javascript:alert(1)</p>');
  });
  it('escapa & dentro do href', () => {
    expect(formatarTexto('https://a.com/?x=1&y=2')).toContain('href="https://a.com/?x=1&amp;y=2"');
  });
});

export function escaparHtml(t: string): string {
  return t
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#39;');
}

/** Conta caracteres Unicode (emoji = 1), sem espaços e quebras nas pontas — igual ao banco. */
export function contarCaracteres(t: string): number {
  return [...t.trim()].length;
}

const URL_RE = /https?:\/\/[^\s<>"']+/g;
const PONTUACAO_FINAL = /[.,;:!?)\]]+$/;

function linhaParaHtml(linha: string): string {
  let saida = '';
  let ultimo = 0;
  for (const m of linha.matchAll(URL_RE)) {
    let url = m[0];
    const pont = PONTUACAO_FINAL.exec(url);
    if (pont) url = url.slice(0, -pont[0].length);
    const inicio = m.index ?? 0;
    const href = escaparHtml(url);
    saida += escaparHtml(linha.slice(ultimo, inicio));
    saida += `<a href="${href}" rel="nofollow ugc noopener" target="_blank">${href}</a>`;
    ultimo = inicio + url.length;
  }
  return saida + escaparHtml(linha.slice(ultimo));
}

/** Texto puro do usuário → HTML seguro: parágrafos, <br> e links http(s). */
export function formatarTexto(t: string): string {
  return t
    .replace(/\r\n?/g, '\n')
    .trim()
    .split(/\n\s*\n/)
    .map((p) => `<p>${p.split('\n').map(linhaParaHtml).join('<br>')}</p>`)
    .join('');
}

export function resumo(t: string, max = 155): string {
  const limpo = t.replace(/\s+/g, ' ').trim();
  const chars = [...limpo];
  if (chars.length <= max) return limpo;
  const corte = chars.slice(0, max - 1).join('');
  const ultimoEspaco = corte.lastIndexOf(' ');
  return (ultimoEspaco > max * 0.6 ? corte.slice(0, ultimoEspaco) : corte) + '…';
}

export function slugify(titulo: string): string {
  const s = titulo
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, 80)
    .replace(/-+$/, '');
  return s || 'topico';
}

export function urlTopico(id: number, titulo: string): string {
  return `/forum/t/${id}-${slugify(titulo)}`;
}

export function idDoParametro(param: string | undefined): number | null {
  const m = /^(\d{1,15})(?:-|$)/.exec(param ?? '');
  if (!m) return null;
  const id = Number(m[1]);
  return Number.isSafeInteger(id) && id > 0 ? id : null;
}

/** Só aceita caminhos internos; evita redirect aberto no login. */
export function caminhoSeguro(volta: string | null | undefined, padrao = '/forum'): string {
  if (!volta || !volta.startsWith('/') || volta.startsWith('//') || volta.startsWith('/\\')) return padrao;
  return volta;

export function tempoRelativo(iso: string, agora: Date = new Date()): string {
  const d = new Date(iso);
  const s = Math.round((agora.getTime() - d.getTime()) / 1000);
  if (s < 60) return 'agora';
  const min = Math.floor(s / 60);
  if (min < 60) return `há ${min} min`;
  const h = Math.floor(min / 60);
  if (h < 24) return `há ${h} h`;
  const dias = Math.floor(h / 24);
  if (dias < 7) return dias === 1 ? 'há 1 dia' : `há ${dias} dias`;
  return d.toLocaleDateString('pt-BR', { day: '2-digit', month: '2-digit', year: 'numeric', timeZone: 'America/Sao_Paulo' });
}

export function ordenarRespostas<T extends { id: number; criado_em: string }>(rs: T[], melhorId: number | null): T[] {
  const melhor = rs.filter((r) => r.id === melhorId);
  const resto = rs.filter((r) => r.id !== melhorId).sort((a, b) => a.criado_em.localeCompare(b.criado_em));

export function lerFiltros(params: URLSearchParams, categorias: string[]): Filtros {
  const cat = params.get('categoria');
  const abaBruta = params.get('aba');
  const aba: Aba = abaBruta === 'sem-resposta' || abaBruta === 'resolvidas' ? abaBruta : 'recentes';
  const busca = (params.get('q') ?? '').trim().slice(0, 100);
  const p = Number.parseInt(params.get('pagina') ?? '1', 10);
  return {
    categoria: cat && categorias.includes(cat) ? cat : null,
    aba,
    busca: busca || null,
    pagina: Number.isFinite(p) && p >= 1 && p <= 1000 ? p : 1,
  };
}

export function urlFiltros(f: Filtros, mudancas: Partial<Filtros>): string {
  const n = { ...f, ...mudancas };
  const sp = new URLSearchParams();
  if (n.categoria) sp.set('categoria', n.categoria);
  if (n.aba !== 'recentes') sp.set('aba', n.aba);
  if (n.busca) sp.set('q', n.busca);
  if (n.pagina > 1) sp.set('pagina', String(n.pagina));
  const qs = sp.toString();
  return qs ? `/forum?${qs}` : '/forum';
}

import type { AutorResumo, Resposta, Topico } from './tipos';
import { nomeExibido } from './exibicao';

const pessoa = (a: AutorResumo | null) => ({ '@type': 'Person', name: nomeExibido(a) });

export function jsonLdTopico(t: Topico, respostas: Resposta[], urlCanonica: string): Record<string, unknown> {
  const resposta = (r: Resposta) => ({
    '@type': 'Answer',
    text: r.corpo,
    dateCreated: r.criado_em,
    url: `${urlCanonica}#resposta-${r.id}`,
    author: pessoa(r.autor),
  });
  const melhor = respostas.find((r) => r.id === t.melhor_resposta_id);
  const outras = respostas.filter((r) => r.id !== t.melhor_resposta_id);
  return {
    '@context': 'https://schema.org',
    '@type': 'QAPage',
    mainEntity: {
      '@type': 'Question',
      name: t.titulo,
      text: t.corpo,
      answerCount: respostas.length,
      dateCreated: t.criado_em,
      author: pessoa(t.autor),
      ...(melhor ? { acceptedAnswer: resposta(melhor) } : {}),
      ...(outras.length ? { suggestedAnswer: outras.map(resposta) } : {}),
    },
  };
}

export function serializarJsonLd(obj: unknown): string {
  return JSON.stringify(obj).replace(/</g, '\\u003c').replace(/>/g, '\\u003e').replace(/&/g, '\\u0026');

    .from('topicos')

  const inicio = (f.pagina - 1) * POR_PAGINA;
  const { data, error, count } = await q
    .order('ultima_atividade', { ascending: false })
    .range(inicio, inicio + POR_PAGINA - 1);
  if (error?.code === 'PGRST103') return { topicos: [], total: count ?? 0 }; // página além do fim
  if (error) throw error;
  return { topicos: (data ?? []) as unknown as TopicoResumo[], total: count ?? 0 };
}

export async function obterTopico(id: number): Promise<{ topico: Topico; respostas: Resposta[] } | null> {
  const c = cliente();
  const [t, r] = await Promise.all([
    c.from('topicos')
      .select(`id, titulo, corpo, categoria, resolvido, melhor_resposta_id, n_respostas, criado_em, editado_em, ultima_atividade, autor_id, ${AUTOR}`)
      .eq('id', id)
      .maybeSingle(),
    c.from('respostas')
      .select(`id, corpo, criado_em, editado_em, autor_id, ${AUTOR}`)
      .eq('topico_id', id)
      .order('criado_em', { ascending: true }),
  ]);
  if (t.error) throw t.error;
  if (r.error) throw r.error;
  if (!t.data) return null;
  return { topico: t.data as unknown as Topico, respostas: (r.data ?? []) as unknown as Resposta[] };
}

import { contarCaracteres } from './texto';

type Campo = HTMLInputElement | HTMLTextAreaElement;

/** Mostra "n/max" e devolve uma função que diz se o valor está dentro dos limites. */
export function ligarContador(campo: Campo, saida: HTMLElement, min: number, max: number): () => boolean {
  const valido = () => {
    const n = contarCaracteres(campo.value);
    return n >= min && n <= max;
  };
  const atualizar = () => {
    saida.textContent = `${contarCaracteres(campo.value)}/${max}`;
    saida.toggleAttribute('data-fora', !valido() && campo.value.length > 0);
  };
  campo.addEventListener('input', atualizar);
  atualizar();
  return valido;
}

/** Guarda o texto na sessionStorage para sobreviver a um novo login. Devolve a função que limpa. */
export function guardarRascunho(campo: Campo, chave: string): () => void {
  try {
    const salvo = sessionStorage.getItem(chave);
    if (salvo && !campo.value) campo.value = salvo;
  } catch { /* storage indisponível */ }
  campo.addEventListener('input', () => {
    try { sessionStorage.setItem(chave, campo.value); } catch { /* storage indisponível */ }
  });
  return () => {
    try { sessionStorage.removeItem(chave); } catch { /* storage indisponível */ }
  };
}

export interface OpcoesEditor {

  corpo: string;

/** Troca o conteúdo por um formulário de edição. `salvar` devolve mensagem de erro ou null. */
export function abrirEditor(o: OpcoesEditor): void {
  const form = document.createElement('form');
  form.className = 'forum-form';
  form.noValidate = true;

  let tituloOk: (() => boolean) | null = null;
  let inputTitulo: HTMLInputElement | null = null;
  if (o.titulo !== undefined && o.limitesTitulo) {
    const campo = document.createElement('div');
    campo.className = 'forum-campo';
    const label = document.createElement('label');
    label.textContent = 'Título';
    inputTitulo = document.createElement('input');
    inputTitulo.value = o.titulo;
    label.append(inputTitulo);
    const cont = document.createElement('span');
    cont.className = 'forum-contador';
    campo.append(label, cont);
    form.append(campo);
    tituloOk = ligarContador(inputTitulo, cont, o.limitesTitulo[0], o.limitesTitulo[1]);
  }

  const campo = document.createElement('div');
  campo.className = 'forum-campo';
  const label = document.createElement('label');
  label.textContent = 'Texto';
  const area = document.createElement('textarea');
  area.value = o.corpo;
  label.append(area);
  const cont = document.createElement('span');
  cont.className = 'forum-contador';
  campo.append(label, cont);
  const corpoOk = ligarContador(area, cont, o.limitesCorpo[0], o.limitesCorpo[1]);

  const erro = document.createElement('p');
  erro.className = 'forum-erro';
  erro.setAttribute('role', 'alert');

  const acoes = document.createElement('div');
  acoes.className = 'forum-acoes';
  const salvar = document.createElement('button');
  salvar.type = 'submit';
  salvar.className = 'forum-btn';
  salvar.textContent = 'Salvar';
  const cancelar = document.createElement('button');
  cancelar.type = 'button';
  cancelar.className = 'forum-btn-sec';
  cancelar.textContent = 'Cancelar';
  acoes.append(salvar, cancelar);

  form.append(campo, erro, acoes);
  o.alvo.hidden = true;
  o.alvo.after(form);
  (inputTitulo ?? area).focus();

  cancelar.addEventListener('click', () => {
    form.remove();
    o.alvo.hidden = false;
  });

  form.addEventListener('submit', async (ev) => {
    ev.preventDefault();
    erro.textContent = '';
    if (tituloOk && o.limitesTitulo && !tituloOk()) {
      erro.textContent = `O título precisa ter entre ${o.limitesTitulo[0]} e ${o.limitesTitulo[1]} caracteres.`;
      return;
    }
    if (!corpoOk()) {
      erro.textContent = `O texto precisa ter entre ${o.limitesCorpo[0]} e ${o.limitesCorpo[1]} caracteres.`;
      return;
    }
    salvar.disabled = true;
    const falha = await o.salvar({ titulo: inputTitulo?.value.trim(), corpo: area.value.trim() });
    if (falha) {
      erro.textContent = falha;
      salvar.disabled = false;
      return;
    }
    location.reload();
  });
}

<script>
  import { obterCliente, sessaoAtual, irParaLogin } from '../../lib/forum/cliente';
  import { forumConfigurado, LIMITES } from '../../lib/forum/config';
  import { mensagemErro } from '../../lib/forum/erros';

  const conteudo = document.getElementById('perfil-conteudo')!;

  async function iniciar() {
    if (!forumConfigurado) { status.textContent = 'Fórum indisponível neste ambiente.'; return; }
    const sessao = await sessaoAtual();
    if (!sessao) { irParaLogin('/forum/perfil'); return; }
    const sb = obterCliente();
    const { data: perfil, error } = await sb.from('perfis').select('nome, apelido, avatar_url').eq('id', sessao.user.id).single();
    if (error || !perfil) { status.textContent = 'Fórum temporariamente indisponível. Tente de novo em alguns minutos.'; return; }

    if (perfil.avatar_url) {

    document.getElementById('form-apelido')!.addEventListener('submit', async (ev) => {
      ev.preventDefault();
      erroApelido.textContent = '';
      const valor = apelido.value.trim();
      if (valor && !apelidoOk()) {
        erroApelido.textContent = `O apelido precisa ter entre ${LIMITES.apelidoMin} e ${LIMITES.apelidoMax} caracteres.`;
        return;

      await sb.auth.signOut();
      location.href = '/forum';

    const erroExcluir = document.getElementById('perfil-excluir-erro')!;

      ev.preventDefault();
      erroExcluir.textContent = '';

        return;
      }
      const { error: e } = await sb.rpc('excluir_minha_conta');
      if (e) { erroExcluir.textContent = mensagemErro(e); return; }
      await sb.auth.signOut({ scope: 'local' });
      location.href = '/forum?conta=excluida';
    });

    status.hidden = true;
    conteudo.hidden = false;
  }

  iniciar();
</script>
